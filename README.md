#  Sistema Musical — Fase 2

##  Sobre o projeto

Este projeto é a continuação do trabalho **Artistas e Músicas**, desenvolvido na primeira fase da disciplina. Nesta etapa, o objetivo é transformar as páginas estáticas em um sistema web dinâmico, utilizando PHP e MySQL para conectar as páginas ao banco de dados.

O sistema permite organizar artistas e músicas, além de gerenciar informações de maneira mais prática.

##  Objetivo

Desenvolver um sistema web funcional, colocando em prática os conhecimentos de desenvolvimento backend e banco de dados.

Durante esta fase, são trabalhados conceitos como autenticação de usuários, gerenciamento de sessões, cadastro, consulta, edição, exclusão e envio de imagens.

##  Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e organização visual.
- **PHP:** processamento das informações e funcionalidades do sistema.
- **MySQL:** armazenamento e gerenciamento dos dados.

##  Funcionalidades

- **Login:** autenticação de usuários para acessar o sistema.
- **Gerenciamento de artistas:** cadastro, consulta, edição e exclusão de artistas.
- **Gerenciamento de músicas:** cadastro, consulta, edição e exclusão de músicas.
- **Upload de imagens:** envio de fotos dos artistas e capas dos álbuns.
- **Biblioteca musical:** visualização das músicas cadastradas.
- **Filtros de pesquisa:** busca de músicas por título, álbum, artista e gênero.
- **Controle de sessões:** proteção das páginas para usuários autenticados.

##  Banco de dados

O projeto utiliza o MySQL para armazenar as informações do sistema.

O banco de dados possui três tabelas principais:

- **usuarios:** armazena os dados de acesso.
- **artistas:** guarda as informações dos artistas.
- **musicas:** armazena os dados das músicas e sua relação com os artistas.

##  Como executar o projeto

Para executar o sistema localmente, é necessário ter um ambiente com PHP e MySQL, como o XAMPP.

1. Instale e inicie o Apache e o MySQL.
2. Coloque a pasta do projeto dentro do diretório `htdocs`.
3. Crie o banco de dados utilizando o arquivo `bd.sql`.
4. Configure a conexão com o banco de dados no arquivo `conexao.php`.
5. Acesse o projeto pelo navegador através do endereço `http://localhost/sistema-musical/`.

##  Aprendizado

A segunda fase tem como objetivo aprofundar os conhecimentos em desenvolvimento web, principalmente na integração entre frontend, backend e banco de dados.

Com isso, o projeto serve como exemplo prático para aplicar os mesmos conceitos na criação de outros sistemas.
